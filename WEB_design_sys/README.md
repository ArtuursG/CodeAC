# 🎨 Color & Font Style Guide

A clean and interactive color and typography style guide designed to help web developers and designers
reference consistent visual standards. This project showcases color palettes and font styles using semantic
HTML and modular CSS.

---

## 🧪 Features

- Color swatch panels for red, green, and blue shades
- Typography section showcasing headings and paragraph styles
- Custom web font: Courgette
- Responsive and centered layout with Flexbox
- Reusable .swatch and .font-sample CSS classes
- Gradient headings and color-coded section labels

---

## 🚀 How to Run

1. Download or clone this repository 
2. Open `index.html` in any modern browser
3. Explore the design samples and color palette layout

---

## 🧰 Tech Stack

- HTML5
- CSS3
- Flexbox
- "@font-face"
- "Google Fonts: Courgette"

---

## 📘 Lessons Learned

- Creating modular CSS structures for style guides
- Using @font-face with web-safe font fallbacks
- Visual presentation of design tokens (colors & fonts)
- Combining HTML semantics with visual clarity
