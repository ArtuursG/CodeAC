# 🏠 House Store - Virtual Paint Department

A responsive web interface for a fictional house supply store specializing in paint education and ordering. The project visualizes color theory using **HSL (Hue, Saturation, Lightness)** and allows users to explore color swatches across three dimensions.

---

## 🧠 What This Project Covers

This project was created to:

- Practice advanced CSS layout and media queries
- Demonstrate interactive visualizations of color theory (HSL)
- Apply typography and responsive images
- Use CSS variables and Flexbox for layout design
- Explore real-world landing page structures

---

## 🧱 Project Structure
```
house-store/
├── index.html # Main HTML layout
├── style.css # Custom styles with media queries and HSL logic
└── README.md # Project documentation
```

---

## 🎨 Features

- Sticky navigation bar with logo swap based on screen size
- Detailed color guide with:
- Red, Green, and Blue base palettes
- Visual swatches changing Lightness, Saturation, and Hue
- Responsive layout using Flexbox and media queries
- Background overlays and layered visual elements
- Google Fonts: "Creepster" for the headline, "Open Sans" for body text
- Demonstrates core color theory principles in CSS

---

## 🚀 How to Run

1. Clone or download this project
2. Open `index.html` in any modern browser

> No build steps or JavaScript required — pure HTML/CSS project
