# 🌍 Excursion – Discover Hidden Places

**Excursion** is a simple, responsive website prototype that showcases a mobile app designed to help users find hidden travel spots around them. The design highlights sleek video previews, elegant typography, and modern layout using HTML and CSS.

---

## 🔧 Features

- Responsive web design
- Embedded autoplaying video
- Clean and modern layout
- Styled using custom CSS
- Coming soon promotional sections
- Optimized for mobile and desktop viewports

---

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in any modern browser.
3. Make sure the following folder structure exists:
```
project-root/
├── index.html
├── resources/
│ ├── css/
│ │ └── style.css
│ ├── images/
│ │ ├── camp.jpg
│ │ └── phone.png
│ └── videos/
│ └── excursion.mp4
```
---

## 🖼️ Assets

- **Video:** `excursion.mp4` (app preview)
- **Images:** Promotional images for camping and mobile app
- **Fonts:** System default (Verdana)
