# 👤 Profile Class Project (C++)

This C++ project implements a customizable `Profile` class that stores personal information such as name, age, location, pronouns, and hobbies. It's a great beginner-to-intermediate object-oriented programming exercise to practice constructors, private data members, vector management, and method encapsulation.

---

## 📂 File Structure
```
profile-project/
├── profile.hpp # Profile class declaration
├── profile.cpp # Profile class implementation
├── main.cpp # Main driver file that creates and displays a profile
└── README.md # Project documentation
```

---

## 🚀 Features

- Stores profile data: name, age, city, country, pronouns
- Dynamically adds and displays hobbies
- Generates a printable bio using `view_profile()`
- Uses `std::vector` to manage hobbies

---

## 🔧 How to Run

1. Make sure you have a C++ compiler installed (e.g., g++, clang++).
2. Compile the files:
- g++ main.cpp profile.cpp -o profile_app
3. Run the program:
- ./profile_app

---

## 🧰 Technologies Used

- C++17 standard
- std::vector, std::string
- OOP (classes, methods, encapsulation)
