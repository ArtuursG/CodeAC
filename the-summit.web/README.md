# ⛰️ The Summit at Breckenridge

A fictional landing page for a winter resort experience in Breckenridge. 
The project demonstrates clean HTML and CSS layout with Google Fonts, fixed navigation, 
interactive activity panels, and a visually appealing banner section.

---

## 🧱 Project Structure
```
summit-breckenridge/
├── index.html           # Main HTML structure
├── style.css            # Project-specific custom styling
├── starting.css         # Provided base styles
├── README.md            # Project overview and documentation
```

---

## 🧪 Features

- Fixed navigation bar with links and logo
- Large full-width banner with background image and overlay text/button
- Informative content section with external links and styled text
- Activity grid styled with Flexbox
- Footer with address
- Interactive hover effects on buttons and links
- Clean typography with Amatic SC and Raleway

---

## 🚀 How to Run

1. Download or clone the repository  
2. Open `index.html` in any modern browser

---

## 🧰 Tech Stack

- HTML5
- CSS3 (Flexbox, gradients, hover transitions)
- Google Fonts (Amatic SC, Raleway)

---

## 📚 Lessons Learned

- Using Google Fonts for stylistic design
- Combining two CSS files: one for structure and one for interactivity
- Responsive layout with Flexbox and consistent margins
- Styling interactive elements (hover, focus, active states)

---

This project follows a Codecademy design spec. It simulates real-world developer tasks: building a responsive, spec-matching layout from provided assets.
