# 🐶 PupSpa - CSS Grid Web Page

## 🔍 What the Project Does

PupSpa is a single-page HTML/CSS project showcasing a dog grooming business layout using modern **CSS Grid**. It demonstrates layout control, responsiveness, and a clean aesthetic design.

---

## 🎯 Why It Was Built

This project was created to:

- Practice **CSS Grid** layout techniques
- Understand grid-based column/row spans
- Create a structured, responsive layout
- Apply Google Fonts and modern design concepts

---

## 🧱 Project Structure
```
├── index.html  # Main HTML layout for the PupSpa website
├── style.css   # Styles using CSS Grid and Poppins font
├── README.md   # Project documentation
```

---

## 🧪 Features

- Responsive layout with **6-column grid**
- Custom sections for:
  - 🐾 Banner and welcome message
  - 🐾 About section
  - 🐾 Address, hours, contact
  - 🐾 Two client testimonials
- Modern font from Google Fonts
- Flexible, maintainable CSS structure

---

## 🚀 How to Run

1. Download the files  
2. Open `index.html` in any modern browser

---

## 🧰 Tech Stack

- HTML5
- CSS3 (Grid layout)
- Google Fonts: [Poppins](https://fonts.google.com/specimen/Poppins)

---

## 📘 Lessons Learned

- How to define grid rows and columns using `grid-template`
- Spanning elements across multiple columns
- Positioning content using `grid-column`
- Combining text, images, and responsive layout elements
