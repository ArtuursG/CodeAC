# 🎨 Dasmoto's Arts & Crafts

A simple HTML project showcasing a fictional arts and crafts store. The webpage presents three main product categories:

- 🖌️ Brushes  
- 🖼️ Frames  
- 🎨 Paint  

Each section includes a product image, description, and pricing information.

## 🌐 Technologies Used
- HTML5  
- CSS3 (linked externally)
