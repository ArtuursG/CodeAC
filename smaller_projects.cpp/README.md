# C++ Mini Projects Collection

This folder contains a series of small, beginner-friendly C++ console 
applications designed to practice basic programming concepts. Each mini-project 
demonstrates a specific programming idea or logic that builds foundational skills 
for larger software development.

---

## 🧰 What You'll Learn
- Variables and Data Types
- User Input & Output
- Random Number Generation
- Conditional Logic & Switch Statements
- Loops (for, while)
- Arrays and Vectors
- String Manipulation
- Basic Game Design (Text-based)
- Function Creation and Organization
- Control Flow and Input Validation

## 💡 How to Use
1. Make sure you have a C++ compiler installed (e.g., g++, clang++).
2. Navigate into the folder of any project and compile it using:
- g++ filename.cpp -o output
- ./output
3. Follow the prompts in the terminal.

---

## 📁 Folder Structure
Each project is self-contained in one `.cpp` file, making it easy to understand and experiment with.
