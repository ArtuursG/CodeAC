# 🍵 Tea Cozy

A fictional tea shop website built with HTML and CSS, inspired by real-world design specs. Tea Cozy offers a responsive layout, clean visuals, and semantic HTML for accessibility.

## 🧪 Features

- Sticky navigation bar with anchor links
- Banner section with mission statement overlay
- Featured teas section with product cards
- Locations section with card-style layout
- Responsive layout using **Flexbox**
- Custom fonts, image assets, and consistent styling

---

## 🚀 How to Run

1. Download or clone the repository  
2. Open `index.html` in any modern browser

---

## 🧰 Tech Stack

- HTML5
- CSS3 (Flexbox, fixed header, image overlays)
- System font: Helvetica
- Image assets included locally

---

## 📘 Lessons Learned

- How to position elements with `flexbox`
- Creating fixed headers and background overlays
- Structuring reusable CSS components
- Maintaining accessibility and clean file structure

---

## 📎 Design Reference

This project follows a Codecademy design spec. It simulates real-world developer tasks: building a responsive, spec-matching layout from provided assets.
