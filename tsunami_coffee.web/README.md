# 🌊 Tsunami Coffee

A fictional coffee shop landing page built with **HTML** and **CSS**. The site emphasizes bold design, responsive layout, and simple navigation — perfect for showcasing the values and culture behind Tsunami Coffee.

---

## 📸 Preview

![Tsunami Coffee](https://content.codecademy.com/courses/freelance-1/unit-5/tsunami-coffee/images/logo.png)

---

## 🧱 Project Structure
```
tsunami-coffee/
├── index.html
├── style.css
└── images/ (CDN-hosted via Codecademy, not stored locally)
```

---

## 🧪 Features

- Full-width header with background imagery and centered branding
- Descriptive company mission section
- Testimonial rating banner
- Three-column image gallery layout
- Location section with map and tagline
- Footer with company nav and copyright
- Media queries prepared for responsive behavior

---

## 🚀 How to Run

1. Clone or download this repository  
2. Open `index.html` in any modern browser

---

## 🧰 Tech Stack

- HTML5
- CSS3 (Flexbox, float-based layout, responsive design)

---

## 📘 Lessons Learned

- Structuring content using nested containers and semantic sections
- Applying Flexbox and float layouts for responsive grids
- Working with remote assets (images hosted via CDN)
- Creating clear typographic hierarchy with rem-based units
- Managing simple media queries for various screen sizes
